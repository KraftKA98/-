# Автомобильные марки и эмблемы

Снимок от 16 ноября 2026 года: **409 уникальных названий с эмблемами**.
Набор включает действующие, исторические и нишевые марки, а также некоторые
автомобильные ателье. Он не заявляется исчерпывающим реестром всех марок мира.

## Источники

1. [filippofilip95/car-logos-dataset](https://github.com/filippofilip95/car-logos-dataset)
   — автор filippofilip / Digitaliko. Снимок коммита
   `e334a4d2e8742108ba164c629dff5636576d3808`.
   Исходная коллекция — 387 записей; используются готовые PNG-миниатюры.
   По README автора изображения получены из Carlogos.org, метаданные и
   организация набора распространяются по MIT, права на эмблемы остаются
   у соответствующих владельцев. Отдельный файл LICENSE в этом снимке
   отсутствует; условия указаны в README источника.
2. [vehiclespecs/brand-logos](https://github.com/vehiclespecs/brand-logos)
   — VehicleSpecs.io. Снимок коммита
   `3f0929e70e0a9a2a502063edc4b3e5c0146cba74`.
   Используется для недостающих марок, в том числе современных электромобилей.
   Полный текст MIT и уведомление об эмблемах сохранены в `CAR_LOGOS_LICENSE.txt`.

Эмблемы используются как обозначения автомобильных марок, без заявлений
о партнёрстве с производителями. Изображения скопированы без перерисовки
и встроены в JSON в формате data URL. PNG проверены декодером, SVG —
XML-парсером и проверками отсутствия скриптов и внешних ссылок.

## Обработка и интерфейс

- Дубли сведены; сохранены привычные названия LADA, ГАЗ, УАЗ, КАМАЗ,
  EXEED, OMODA, MINI, Škoda и другие.
- Убраны записи отдельных моделей и подразделений: например, Toyota Crown,
  Chevrolet Corvette, Ford Mustang, Nissan GT-R, Audi Sport и BMW M.
- Легковые отделены от явно грузовых и мотоциклетных марок. Имеющиеся
  марки сайта, для которых нет изображения в источниках, сохранены текстом.
- В подсказках, у выбранной марки и в карточке желания показывается эмблема.
  Для водного транспорта и одежды не подставляется автомобильная эмблема
  одноимённого бренда. При сбое загрузки остаётся текстовое обозначение.
- Добавлены русские варианты названий и сохранён ручной ввод отсутствующей
  марки. Модель автомобиля вводится отдельным полем.

`car-brands.js` — компактный индекс названий; `car-logos.json` — локальный
пакет изображений примерно 4,4 МБ, который запрашивается только при первом
показе автомобильных эмблем. Отдельные внешние запросы за логотипами не нужны.
`car-brand-ui.js` подключает марки и отображение эмблем к существующему выбору.

Сборка из двух скачанных репозиториев:

```sh
python scripts/build-car-brands.py /path/car-logos-dataset /path/brand-logos
```

Проверки: `node tests/car-brands.test.cjs`, проверки справочников, формы
и браузерный сценарий `tests/browser-smoke.cjs` на 390 и 1440 px. Изображения
проверены фактической загрузкой и декодированием в Chromium.
