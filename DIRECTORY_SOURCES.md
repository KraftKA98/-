# Справочники городов и брендов

## Города

`cities-data.js` содержит 1126 записей «город — регион».

Основной источник: [hflabs/city](https://github.com/hflabs/city), файл
[city.csv](https://github.com/hflabs/city/blob/ae661bffe572880472249097c9b29c42b09650ea/city.csv).
Авторы исходного справочника: HFLabs; данные об адресах получены авторами
через DaData.ru, перечень городов — из Википедии. Последнее изменение
исходного CSV: 11 октября 2021 года. Загружен 16 ноября 2026 года.

Лицензия исходного и адаптированного справочника:
[Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/).
При распространении адаптированного файла сохраните указание авторов,
источника, лицензии и изменений. Лицензия относится к городским данным,
не устанавливает лицензию остальных файлов приложения.

Изменения для ХОЧУ:

- Оставлены названия городов и регионов; исправлен выбор вложенного города
  (например, Алупка вместо административного центра Ялты).
- Унифицированы полные названия регионов для отображения.
- Ростов Ярославской области отображается как Ростов Великий;
  старое название сохранено как поисковый вариант.
- Добавлены получившие городской статус Колтуши, Ачхой-Мартан, Бугры,
  Тельмана, Наурская, Ойсхара, Серноводское, Шелковская и Новоселье.
- Дополнения и покрытие названий сверены с открытым справочником
  [arbaev/russia-cities](https://github.com/arbaev/russia-cities),
  обновлённым в ноябре 2026 года. Все названия из этого справочника найдены
  в итоговом наборе с нормализацией «е/ё», пробелов и дефисов.

Состав и территориальная группировка исходного набора сохранены;
файл является справочником адресных подсказок. Полнота ограничена
охватом источников: это не реестр всех сёл, посёлков и других населённых
пунктов. Чтобы не блокировать пользователей, разрешён ручной ввод города.

Воспроизведение сборки:

```sh
curl -fL https://raw.githubusercontent.com/hflabs/city/ae661bffe572880472249097c9b29c42b09650ea/city.csv -o /tmp/city.csv
python scripts/build-cities.py /tmp/city.csv
```

Города с одинаковыми названиями различаются по региону. Для них в поле
сохраняется строка `Город (Регион)`, для остальных — название города.
В старых заявках регион может отсутствовать: такие данные не переписываются.
Серверные подписки по-прежнему сравнивают строки города точно; для старой
подписки без региона на одноимённый город может потребоваться пересоздание.

## Бренды

`brands-data.js` — вручную составленные списки подсказок для категорий
и подкатегорий; это не полный реестр всех товарных знаков. Названия нужны
для описания желаемых товаров и не означают партнёрство с правообладателями.
Для автомобильных марок добавлены эмблемы; источники и условия использования
описаны в `CAR_BRAND_SOURCES.md`. Для остальных товарных брендов используются
только названия.

Подсказки для техники разделены по типам устройств. Для остальных товарных
разделов есть собственные списки. Доступен свободный ввод отсутствующего
бренда. В недвижимости, работе и путешествиях поле не показывается;
для животных оно относится к товарам и кормам, а не к породе питомца.

Бренд сохраняется в существующем описании строкой `Бренд / марка: …`.
Фильтр использует эту строку, а для старых заявок ищет название и варианты
написания в заголовке и описании. Список подсказок и городов работает локально:
для его поиска не нужны API-ключи и обращения к внешним сервисам.
